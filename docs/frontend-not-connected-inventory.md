# Frontend “Not connected yet” inventory

Date: 2026-11-19

## Scope and method

The visible message is generated by the shared `Unavailable` component in `frontend/src/ui.tsx`: it renders “{item} is not connected yet”. I mapped the navigation destinations in `frontend/src/App.tsx` to their page components, then inspected each page's calls to `Unavailable`. This distinguishes exact message locations from individual empty data panels.

The browser click-through could not be completed: the computer-use inventory timed out twice with a service-info timeout. This is a source-based catalog of the current GitHub `main` frontend, not a claim that every destination was visually clicked. The browser's workspace selector, Local/Render API switch, preview toggle, theme, Access dialog, search and sidebar collapse are controls rather than additional pages; no “not connected yet” message is produced by the controls themselves.

## Routes with no exact message on the route itself

These destinations may show a different empty/error state or a working preview; they do not call `Unavailable` at the top level described here:

- `/` — Home: product overview and links to workspaces.
- `/investigations/:id` — shows “No authorized investigation detail” when no case is selected; its Evidence and Hypotheses tabs can show the exact phrase when a case exists.
- `/investigations/review` — pilot mode and synthetic preview show a safety notice or preview controls; simulator mode can show the Pending simulator reviews entry above.
- `/recordings/quality` — Data quality continuity panel says “No gaps in the bounded window” when none are found.
- `/knowledge` — Knowledge landing page: links to manuals, memory and investigation history.
- `/lab/runs/:runId` — managed run detail has its own route and nested tabs; its exact messages are listed above.

## Navigation map

The sidebar contains 22 destinations across Workspace (6), Equipment (5), Research (7) and Engineering (4). Investigation detail and managed run detail are additional routes reached from records, and their tabs expose more messages. Routes and labels are taken from the `nav` array in `frontend/src/App.tsx`; route components are exported by `frontend/src/pages.tsx`. Subpages are listed in the table above where they have a placeholder message.

## Interpretation

“Not connected yet” is a shared empty-state message, not one backend integration issue. Its detail varies by panel: some require a recorder capture, some require an evaluator or investigation file, and others require an API capability. The UI is intentionally explicit when it has no approved source rather than filling those panels with synthetic values (except in the separately labeled preview mode).
